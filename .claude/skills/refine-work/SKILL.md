# Refinement Assessment

## 1. Identify the batch
- Read provided issue numbers or descriptions.

## 2. Per issue, draft
- **Goal**, restated in your own words.
- **Risk / blast-radius summary** — check layer/permission impact. Use `codegraph_explore` if a specific class/screen is known.
- **Approach options** — 2–3 plausible ways to implement it.
- **Effort/complexity signal** — XS / S / M / L / XL.

## 3. Present the batch — checkpoint
Present the summary table to the user for discussion.
